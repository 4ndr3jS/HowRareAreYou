# How Rare Are You?

Its a very fun probability calculator built with **vanilla HTML, CSS, and JavaScript**. Enter a few personal traits and find out how many people on Earth share your exact combination. Don't worry everything runs locally on your computer so no data stealing and collection.

---

## Features

* Height rarity using country-specific normal distributions (two-tailed probability)
* Birthday rarity based on real seasonal birth frequency data (CDC NVSS)
* Step-by-step probability chain showing how each trait multiplies in
* Visual charts: bell curve with shaded tails, birth month bar chart, handedness bars
* Metric / imperial unit toggle for height
* Fully self-contained, no server, no tracking, no external dependencies

---

## Tech stack

* **HTML**
* **CSS**
* **JavaScript**
* **Local CSV-like array**
